# AWS Deployment Summary

## Overview
The Cloud Native E-Commerce application has been successfully deployed to an AWS EC2 instance running K3s Kubernetes. The deployment provisions fully managed AWS infrastructure using Terraform, builds and pushes Docker images to Amazon ECR using Jib, and applies Kubernetes manifests using Kustomize.

## Access and Credentials

### Connecting to the Host
You can SSH into the EC2 host using the generated key pair:
```bash
ssh ubuntu@16.192.143.255
```

### Accessing the Kubernetes Cluster
To interact with the cluster locally, use the generated kubeconfig:
```bash
# 1. Copy the kubeconfig locally
scp ubuntu@16.192.143.255:/etc/rancher/k3s/k3s.yaml ./kubeconfig

# 2. Configure kubectl
export KUBECONFIG=./kubeconfig
kubectl get nodes
```
*(Note: TLS verification may need to be skipped: `kubectl config set-cluster default --insecure-skip-tls-verify=true`)*

### Secrets Storage
Plaintext passwords for MySQL, Keycloak, and Grafana have been securely generated by Terraform and stored in:
- `k8s/generated/generated-secrets.env` (Excluded via `.gitignore`)
The Kubernetes cluster has these injected securely as `cloud-db-secrets` and `platform-secrets`.

- **Keycloak Auth**: `http://auth.16.192.143.255.nip.io`
- **Grafana Dashboard**: `http://grafana.16.192.143.255.nip.io`
- **Prometheus UI**: `http://prometheus.16.192.143.255.nip.io`
- **Zipkin Tracing**: `http://zipkin.16.192.143.255.nip.io`

*Note: The nip.io domain resolves to your Elastic IP. If it fails due to local DNS, modify your `/etc/hosts` to point these domains to `16.192.143.255`.*
